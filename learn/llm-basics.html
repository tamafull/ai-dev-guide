LLMは「次に来るtoken」を予測し続けて文章を作る

LLMの中核は、ここまでのtoken列から次tokenの確率分布を出すことです。このページでは、まず外部ライブラリなしの小さな言語モデルを動かし、その後でTransformer型LLMでは何が増えるのかをつなげて理解します。

このページでやること

Pythonだけで文字単位のbigram言語モデルを作り、短い文章から遷移確率を学習し、実際に文章を生成します。これはLLMではありませんが、「学習データから次tokenの確率を覚え、1tokenずつ生成する」という最小原理をそのまま観察できます。

1. まず最小の言語モデルを動かす

Python 3.10以降があれば動きます。`tiny_lm.py` を作り、次を保存します。

from collections import defaultdict, Counter
import random

text = """AIは文章を生成する。AIは次の文字を予測する。
文章は文字の並びでできている。予測を繰り返すと文章になる。"""

counts = defaultdict(Counter)
for a, b in zip(text, text[1:]):
    counts[a][b] += 1

probs = {}
for a, counter in counts.items():
    chars = list(counter.keys())
    weights = list(counter.values())
    probs[a] = (chars, weights)

def sample_next(ch):
    chars, weights = probs.get(ch, (["。"], [1]))
    return random.choices(chars, weights=weights, k=1)[0]

def generate(start="A", length=80):
    out = [start]
    for _ in range(length - 1):
        out.append(sample_next(out[-1]))
    return "".join(out)

for _ in range(5):
    print(generate("A"))

python tiny_lm.py を実行すると、学習文に似た文字列が生成されます。意味はかなり壊れますが、同じ文字の後に何が出やすいかは反映されます。

2. 何を学習したのかを見る

次のコードを末尾へ足します。

for ch in ["A", "I", "は", "文", "予"]:
    print(ch, counts[ch].most_common())

たとえば「A」の次は「I」がほぼ確実、「文」の次は「章」が多い、といった遷移が見えます。このモデルが見ている文脈は直前1文字だけです。だから長い依存関係は扱えません。

3. LLMでは何が違うのか

現在のLLMは、直前1tokenだけではなく長いtoken列を入力し、Transformerで各token同士の関係を何層も計算します。学習の基本目標は依然として「正しい次tokenの確率を上げる」ことです。

大まかには次の流れです。

  1. 文章をTokenizerでtoken IDへ変換する。
  2. Embeddingでtoken IDをベクトルへ変える。
  3. Transformerが文脈を混ぜる。
  4. 語彙数ぶんのlogitを出す。
  5. 正解tokenとのcross entropy lossを計算する。
  6. backpropagationで重みを更新する。

4. 「確率を出す」と「文章を生成する」は別

モデルは次tokenの確率分布を返します。そこから何を選ぶかはsampling側の仕事です。常に最大確率を選ぶと同じような文章になりやすく、温度を上げると珍しいtokenも選ばれやすくなります。

import math, random

def sample_with_temperature(logits, temperature=1.0):
    scaled = [x / temperature for x in logits]
    m = max(scaled)
    exp = [math.exp(x - m) for x in scaled]
    total = sum(exp)
    probs = [x / total for x in exp]
    return random.choices(range(len(logits)), weights=probs, k=1)[0]

temperatureは「モデルの知識量」を変える設定ではありません。同じlogitからどれだけ保守的・多様に選ぶかを変えます。

ChatGPTへ会話中に情報を教えても、通常その場でモデルの重みが再学習されるわけではありません。会話履歴やMemoryなどが入力コンテキストとして使われるのと、fine-tuningで重みを更新するのは別です。

6. 自分で確かめる実験

bigramモデルの学習文を変えて、次を試してください。

  • 同じ語句を10回追加すると、生成頻度がどう変わるか。
  • 学習データを10倍にすると、文章らしさがどう変わるか。
  • bigramを「直前2文字→次1文字」に変えると何が改善するか。
  • 未知の先頭文字を入れたとき、なぜ破綻するか。

ここまでで、「学習データ」「文脈長」「確率分布」「sampling」が別々の要素だと見えてきます。
