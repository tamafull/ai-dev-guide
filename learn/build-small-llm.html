Learn · Build a tiny LLM

最初は「賢いLLM」ではなく、学習ループが見える小さいモデルを作る

ChatGPT級を自宅で一から学習する必要はありません。数MBの文章と小さなTransformerでも、token化、損失計算、逆伝播、生成というLLMの基本構造を体験できます。

最小構成

  1. 短いテキストデータを用意する。
  2. 文字または小さなTokenizerでID列へ変換する。
  3. 小さなTransformerを作る。
  4. 「次token予測」のcross entropyを下げる。
  5. 学習後に1tokenずつ生成してみる。

最初はGPUがなくても動くサイズに落とし、モデルが文章のパターンを徐々に覚える様子を見るのが目的です。

教材はnanoGPTより新しいnanochatも確認する

Andrej KarpathyのnanoGPTは読みやすい実装として有名ですが、本人も2025年に後継のnanochatを案内しています。古い教材を使う場合は「仕組みを学ぶ教材」として扱い、現在の実運用構成と同一視しない方がよいです。

次の段階

一からの学習を体験したら、既存モデルを使う、LoRAで調整する、RAGで知識を足す、Evalsで比較する、という順へ進むと実用側へつながります。
