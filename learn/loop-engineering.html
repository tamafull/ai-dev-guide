Learn · Loop Engineering

Loop Engineeringは、AIが「試す→見る→直す」を繰り返す仕組みを設計する

Promptを一度工夫して終わりではなく、AIが行動し、結果を観察し、必要なら修正してまた試す反復そのものを設計する考え方です。2026年にはIBMもこの語を、agentic workflowのループ設計を表す言葉として紹介しています。

最小のループ

  1. Goalを読む。
  2. 次の行動を決める。
  3. ツールやコードを実行する。
  4. 結果を観察する。
  5. 成功条件と比較する。
  6. 未達なら方針を修正して続ける。

Loop Engineeringで決めるもの

  • いつ再試行するか。
  • 何回失敗したら止まるか。
  • どの結果を「成功」と判定するか。
  • どの操作は人間承認が必要か。
  • 状態をどこへ残すか。
  • 失敗から何を次の入力へ戻すか。

例

コード修正なら「実装→テスト→失敗ログを読む→修正→再テスト」がループです。調査なら「仮説→検索→証拠比較→不足点を再検索」がループになります。AITuberなら「発話→視聴者反応→会話状態更新→次の発話」もループです。
