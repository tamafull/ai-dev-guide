MCPは、AIと外部ツール・データをつなぐための共通規格

Model Context Protocol（MCP）は、LLMアプリが毎回専用実装を書かなくても、外部データや操作を共通の形で発見・利用できるようにするオープンプロトコルです。

何を公開するのか

現在のMCPでは、主にTools、Resources、Promptsといったprimitiveを通じて能力や情報を提供します。AIアプリ側は、サーバーが何を提供しているかを発見し、必要なものを呼び出します。

例

GitHub、Google Drive、DB、社内APIをそれぞれMCP serverとして公開すれば、MCP client対応のAIから共通の仕組みでアクセスできます。MCPは「AIが賢くなる仕組み」ではなく、外部能力への接続方法です。

注意点

接続できる能力が増えるほど、権限と認証が重要になります。読み取りだけでよいAgentへ削除や本番変更の権限まで渡さないようにします。

現在の仕様は変化が速い

MCPは活発に更新されています。実装時は古いブログ記事だけでなく、現在の仕様と使うSDKのバージョンを確認します。
