2026 — 「チャット」から、長時間動くエージェントへ

2026-02-11 · 開発手法

人間がコードを書くより、エージェントが働ける環境を設計する

代表: Codexを使ったagent-first開発。

主な使われ方: 人間は目的、制約、リポジトリ構造、テスト、lint、レビューの仕組みを設計し、エージェントが実装・テスト・修正を繰り返す。OpenAIの事例では、3人のエンジニアが約5か月で約100万行、約1,500 PRをCodex主体で構築したと報告している。

転換点: 「良いプロンプトを書く」だけではなく、エージェントが迷わず検証できるハーネスやリポジトリ設計が主要テーマになった。

OpenAI — Harness engineering

2026-04-16〜 · エージェント利用

コーディングエージェントがIDEの外へ広がる

代表: Codex app / computer use / 複数エージェント。

主な使われ方: コード編集だけでなく、PRレビュー、ブラウザ確認、リモート開発環境、繰り返し作業、複数エージェントの並列実行へ広がった。OpenAIは2026年、Codex利用が技術職以外の自動化や分析にも広がったと報告している。

転換点: AIの利用単位が「質問1回」から「仕事1件」へ移り、監督・権限・再開・実行履歴の設計が重要になった。

2025 — コード補完から「仕事を任せる」コーディングエージェントへ

2025-02-24 · モデル / 開発ツール

Claude Code登場。ターミナルでリポジトリ全体を扱う形が広がる

代表: Claude 3.7 Sonnet、Claude Code。

主な使われ方: ファイルをまたいだ変更、テスト実行、コマンド操作、コードベース調査など、IDEの補完より長い作業をAIへ任せる。

転換点: 「次の数行を書くAI」から「リポジトリを読み、計画し、変更し、検証するAI」へ重心が移った。

Anthropic — Models / Claude 3.7 Sonnet and Claude Code

2025-03-11 · エージェント基盤

モデル単体ではなく、検索・ファイル・コンピュータ操作を組み合わせる

代表: OpenAI Responses API、Agents SDK。

主な使われ方: Web検索、ファイル検索、computer useなどのツールを組み込み、複数ステップの処理をエージェントとして実装する。

転換点: LLM APIが「文章を返すAPI」から「ツールを使って仕事を進める実行基盤」へ広がった。

OpenAI — New tools for building agents

2025-05-16 · コーディングエージェント

Codexがクラウド上で複数タスクを並行処理する

代表: Codex / codex-1。

主な使われ方: バグ修正、機能追加、コードベースへの質問、テスト、PR提案をクラウドサンドボックスで非同期に実行する。

転換点: 開発者がAIと同じ画面で1ターンずつ作業する形から、タスクを委任し、後で成果物をレビューする形が一般化し始めた。

2024 — マルチモーダル、推論、外部ツール接続が揃う

2024-05-13 · モデル

GPT-4oでテキスト・画像・音声を一つの対話へ

代表: GPT-4o。

主な使われ方: 文章だけでなく、画像の内容を見ながら質問する、翻訳する、音声で会話するなど、入力形式をまたいだ支援。

転換点: 「テキストチャット」が中心だった生成AIが、画面・画像・音声を扱う汎用インターフェースへ近づいた。

OpenAI — Introducing GPT-4o

o1で「すぐ答える」以外のモデル設計が前面に出る

代表: OpenAI o1-preview / o1-mini。

主な使われ方: 数学、科学、競技プログラミングなど、即答より複雑な推論を重視する問題。

転換点: モデル選びに「速い会話モデル」と「時間を使って考える推論モデル」という軸が加わった。

OpenAI — Learning to reason with LLMs

2024-10-22〜11-25 · ツール利用

AIが画面を操作し、MCPで外部データへつながる

代表: Claude 3.5 Sonnet computer use、Model Context Protocol (MCP)。

主な使われ方: GUI操作、開発環境や社内データへの接続、AIから外部ツールを呼び出す仕組みづくり。

転換点: 「モデルに情報を貼る」から「モデルが必要な情報・ツールへ自分でアクセスする」設計へ進んだ。

2022 — ChatGPTで「プロンプトを書く人」から「会話する人」へ

2022-11-30 · 会話AI

ChatGPT登場。生成AIが専門家向けAPIから一般の会話UIへ

代表: ChatGPT（GPT-3.5系）。

主な使われ方: 質問応答、文章作成、要約、学習、コード相談。前の発言を踏まえて何度も修正する対話型の使い方が広がった。

2021 — AIコーディングは「補完」から始まった

2021-06-29 · コーディングAI

GitHub Copilot登場。AIがIDEの中で次のコードを提案する

代表: OpenAI Codex、GitHub Copilot。

転換点: 開発者がAIへ別画面で質問するのではなく、IDEの作業フローへAIが常駐する形が実用化した。

2020 — 汎用LLMをAPIから呼ぶ時代
