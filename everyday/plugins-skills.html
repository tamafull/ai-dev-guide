Plugins & Skills · 2026-10-27

プラグインは「できること」を増やし、Skillは「やり方」を残す

AIに毎回同じ説明をするより、外部サービスへの接続はプラグイン、再利用したい手順はSkillに分けます。組み合わせると「Gmailを読む」だけでなく「予定とメールから毎回同じ形式の会議準備を作る」といった使い方ができます。

最初に試しやすい組み合わせ

Gmail + Google Calendar

メールから背景を拾い、予定を確認して会議準備、旅行予定、締切確認をまとめます。

Slack / Teams + Drive / Notion

会話と資料を横断して、決定事項、未解決点、次の作業を集めます。

GitHub + Linear / Jira系

Issue、PR、レビュー、関連コードをつないで開発状況を追います。

Figma / Canva

文章だけでなく、デザイン素材やビジュアル作成へつなげます。

Skillに向いているのは「毎回ほぼ同じ手順」

毎週の会議準備、旅行の持ち物、学習ノート、支出レビューなど、入力だけ変わる処理はSkillにします。

毎回、予定を確認 → 関連メールを探す → 目的 / 決定事項 / リスク / 次の行動に整理 → 元情報へのリンクを残す。推測で不足を埋めない。

一度よい出力を作ってからSkill化すると、曖昧な手順をそのまま固定しにくくなります。

おすすめは「大量に入れる」より、生活のボトルネックから1〜2個

プラグインは多いほど便利とは限りません。まず、自分が毎日何度も開くサービスか、情報が散らばって困っている場所から始めます。読み取りだけで十分な段階では、送信・削除などの強い権限を広げすぎない方が安全です。
