「答えて」ではなく「終わらせて」が必要ならWorkを使う

Chatは考える・相談するのに向き、Workは複数のアプリやWebをまたいで情報を集め、成果物まで作る仕事に向きます。さらに専用プラグインがない操作はBrowser / Computer / Chromeで画面を使えます。

ChatとWorkの境目

例向く場所
「この旅行先どう思う？」Chat
メールの予約、カレンダー、Webの営業時間から旅程を完成させるWork
文章の相談、アイデア出しChat
複数ファイルを読み、文書とスライドを完成させるWork

専用プラグインがあるなら先に使う

Gmailを読むならGmail、CalendarならCalendarのような専用プラグインの方が、画面クリックより速く構造化された情報を扱えます。画面上でしかできない操作や、対応プラグインがないサイトではBrowser / Computer / Chromeを使います。

こんなことができる

  • ログイン済みサイトのフォームを下書きし、送信前に確認する。
  • スプレッドシートを画面で見ながら異常箇所を探す。
  • 複数サイトを巡回して条件に合う情報を集める。
  • Webアプリを操作して表示崩れや手順を確認する。
  • デスクトップアプリの設定変更を補助する。

GeminiのComputer useでMacのアプリをまたぐ

GeminiアプリのTaskで @Computer use を指定すると、許可したmacOSアプリやブラウザをクリック、入力、スクロール、メニュー操作できます。操作は仮想画面で進み、ライブプレビューを見ながら停止できます。Downloadsの領収書から経費アプリへ転記する、写真をLightroomへ取り込んで整理する、といったGUI中心の作業に向きます。

2026年11月27日時点では、日本・米国・インド・韓国で英語UIを使う18歳以上の個人Googleアカウントが対象です。Gemini AI Plus / Pro / Ultraの契約とGeminiアプリのMac版が必要で、仕事用・学校用アカウントは対象外です。

Settings → Computer useでアプリを許可・ブロックします。まずは対象アプリを絞り、Terminal、パスワード管理、決済アプリ、機密情報を扱うアプリは必要性を確認するまで許可しない方が安全です。Googleは、ログイン済みセッションや画面に表示されたMFAコードへアクセスできる可能性、画面内の悪意ある指示が別アプリの操作を誘導するリスク、バックアップは常に成功するとは限らず、作成されても24時間または次のpromptまでの短期保持です。

強い操作は確認を残す

送信、購入、削除、契約変更などは、情報収集や下書きとは分けます。「ここまでは自動、ここから先は確認」と境界を先に指定すると扱いやすくなります。
