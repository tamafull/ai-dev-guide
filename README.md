# AI開発ガイド v0.1

生成AI・AIエージェントをソフトウェア開発で使うための、継続更新型の実務ガイドです。

## 開き方

- `index.html` をブラウザで開いてください。
- GitHub Pages / Cloudflare Pages / Netlify などにそのまま配置できます。
- 外部ライブラリ依存なし。HTML/CSS/JavaScriptのみです。

## 更新方針

- 本文は常に「現在の推奨」を示します。
- 古い結論は本文に残さず、変更理由を `changelog.html` に記録します。
- 根拠は `evidence.html` に集約します。
- 未採用・保留中の知見は `candidates.html` に残します。
- 専門用語は `glossary.html` に集約し、本文から内部リンクします。
