# AI開発ガイド

生成AI・AIエージェントをソフトウェア開発で実務利用するための、継続更新型ガイドです。

公開サイト: https://tamafull.github.io/ai-dev-guide/

## 構成

- `index.html` — 現在の実務指針
- `glossary.html` — 日本語中心の用語集
- `style-guide.html` — 人間が読みやすい形を保つための執筆規約
- `assets/style.css` — 共通スタイル

## 更新方針

- 本文は「現在の推奨」を優先します。
- 新しい知見が既存の結論を覆した場合は、本文を最新の結論へ更新します。
- 一般的な日本語がある専門用語は、日本語を主表記にします。英語は初出や検索用に併記します。
- 結論を先に置き、短い段落、具体的な見出し、統一した用語を使います。
- 重要な新規知見がない場合は、不要な更新を行いません。
